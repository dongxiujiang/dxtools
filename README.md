用 Python 做一个本地考试系统（桌面窗口、中文界面、能直接运行）。

功能：
1. 开始页：介绍试卷构成，点按钮开始考试。
2. 答题页：一次显示全部 50 题（可滚动），单选 40 题每题 2 分、判断 10 题每题 2 分，
   顶部实时显示已作答进度，可点按钮交卷。
3. 结果页：显示总分和正确数，逐题列出「你的答案 / 正确答案 / 对错 / 解析」，
   并能一键重新随机出一套新卷。

题目要围绕 7 个主题：网络安全、网络协议与端口、系统与办公基础、服务器与机房运维、
数据管理、信息安全、运维规范。题库量大一些，每次抽题随机、选项顺序随机，
这样每次试卷都不一样。




帮我做一个「在线刷题式」考试桌面软件，重点是用起来顺手：

- 打开就是开始页，点「开始考试」直接进答题，不用注册登录。
- 答题页是一整页可滚动的答题卡，一道题一个卡片，题干 + 4 个选项（判断题就两个按钮）。
  点选项文字那一行任意位置就能选中，不用非得点小圆点。
- 顶部显示「已作答 X / 50」，没答完点交卷会弹窗提醒。
- 交卷后给总分，然后每道题一张卡片：答对绿色边框、答错红色边框，
  写明你选了什么、正确答案是什么、为什么对/为什么错。
- 结果页底部一个按钮，点一下重新抽一套全新的题再考一次。

题库内容覆盖 IT 运维和信息安全常识，中文，Windows 下双击就能跑。



用 Python 做一个本地考试系统，要求做完我能直接运行、不报错。

必须满足：
1. python 环境下 pip 装好依赖就能跑，双击 main.py 出窗口。
2. 试卷固定 50 题 = 40 单选（2 分）+ 10 判断（2 分），满分 100。
3. 每次开始考试都是随机抽题、随机打乱选项，不重复。
4. 答题界面：单选点选项文字即可选中（点整行，不是只有小圆点）；
   顶部实时显示答了多少题；交卷时若有漏答要弹窗提醒。
5. 考完显示总分；下面逐题展示：对错、你的答案、正确答案、解析。
6. 能一键重考（重新随机出题）。
7. 题库主题：网络安全、网络协议与端口、系统与办公、机房运维、数据管理、信息安全、运维规范。
8. 界面是中文，字号别太小，Windows 上看得清。

注意：答题的交互代码写完后自己测一遍——我点选项文字时不能崩溃闪退。
